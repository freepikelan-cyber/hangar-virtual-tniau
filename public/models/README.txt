SLOT MODEL 3D .GLB OTOMATIS (HANGAR VIRTUAL TNI AU)
====================================================

Taruh file .GLB hasil export dari Meshy.ai / Tripo3D / Blender ke folder ini dengan nama persis berikut:

1. gsuit.glb          -> Otomatis tampil di menu "G-Suit" (Baju Pilot Tempur & Anti-9G)
2. pilot-helmet.glb   -> Otomatis tampil di menu "Helm" (Helm Pilot Tempur HGU-55/P + NVG + Masker MBU-20)

Skala, posisi tengah, dan pijakan bawah akan dinormalkan secara otomatis agar langsung pas dengan 10 pin edukatif 3D dan rotasi 360°.
Anda juga bisa mencoba file .GLB secara instan lewat tombol "Muat .GLB" di bilah bawah saat membuka menu G-Suit atau Helm.
