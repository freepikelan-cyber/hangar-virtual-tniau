# Hangar Virtual Alutsista TNI AU 3D

Aplikasi web edukasi dirgantara 3D interaktif untuk mengeksplorasi **8 armada utama TNI Angkatan Udara** secara *real-time* (360°), dioptimalkan untuk layar sentuh Smartboard 16:9 maupun laptop/desktop.

## Fitur Utama
- **8 Armada TNI AU 3D**: F-16 Fighting Falcon (`TS-1601`), Sukhoi Su-30MK2 (`TS-3005`), Dassault Rafale (`TS-0301`), C-130J Super Hercules (`A-1339`), Boeing 737-400 VIP (`A-7304`), KAI T-50i Golden Eagle (`TT-5007`), KT-1B Woongbi *Jupiter Aerobatic Team* (`LL-0108`), dan H225M Caracal (`H-7206`).
- **HUD Militer Futuristik**: Tema *Deep Navy* dengan panel *Glassmorphism* *collapsible*, pencarian armada *real-time*, dan filter kategori.
- **Mode Inspeksi Interaktif**: **X-Ray**, **Wireframe**, **Pin Hotspot 3D** (5 komponen per pesawat dengan *smooth camera focus*), **Putar 360°**, dan **Simulasi Mesin** (*afterburner*, asap aerobatik, rotasi baling-baling/rotor, & *hovering*).
- **Kuis 3D Interaktif**: Uji pengetahuan dengan mengetuk langsung komponen pada model 3D pesawat lengkap dengan umpan balik instan dan skor akhir.

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

## Build Produksi

```bash
npm run build
```
